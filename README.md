
# PhutSmileSmp - PSCore

Core plugin for the PhutSmileSmp Minecraft economy server.

## Requirements

- Java 21
- Paper 1.21.11+
- Maven 3.9+
- GitHub Actions (for automated builds)

## Build

Run:

```bash
mvn clean package
```

The plugin JAR will be generated at:

```text
target/PSCore.jar
```

## Main features planned

- Economy and player statistics
- Auction House
- Player Orders
- Server Sell / Price / Worth
- Home and teleport systems
- Random teleport across three worlds
- Combat system
- Scoreboard and settings
- Staff tools and account security
- Transaction recovery and item protection

## Compatibility

The plugin targets Paper servers. Bedrock players are supported
through GeyserMC and Floodgate installed separately.

## Important

This project is under development.
A successful compilation does not prove that every feature
has passed live server testing.
